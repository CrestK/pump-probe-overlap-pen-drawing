Pen plotter · two Gaussian beams in vacuum

Beam Overlap Drawing

A pump and a probe beam, two Gaussian beams crossing in a pump–probe experiment, as a 3-D contour plot for a pen plotter. Each beam is drawn as its 1/e² envelope plus slices across the beam. In every slice the intensity contours are concentric rings, so you can follow the intensity along the beam: the rings crowd into the focus and thin out where the beam spreads. Underneath, the 2PA and 1PA signal show where along z each process happens. Each beam is one pen and one SVG.

Signal along z

Signal generated per µm of depth along the z axis, with a line at every probe slice. 2PA (a pump and a probe photon absorbed together) goes as ∫ Ipump·Iprobe dx dy, so it comes only from where the beams overlap. 1PA goes as ∫ I dx dy, the beam power, which is the same at every depth. Both curves hold the same area, the same total signal.

Plotting it

Made for strek on a Bambu Lab P2S with a pen module, and works with any tool that reads SVG polylines.

With strek

  1. Download both SVGs.
  2. Open strek and drop both files at once. Each file becomes one pen layer, and layers loaded together share one placement, so the colours line up. Layers plot top to bottom; put the lighter ink first so the darker lines stay crisp where they cross.
  3. Pick the same paper as here. The drawing already fits inside the margin, so strek plots it at 100% and centres it on the sheet.
  4. Download the G-code and run it. The printer pauses after homing for you to mount the first pen, and again between layers to swap pens. Don't move the sheet.

The files

  • 1 SVG unit = 1 mm. The page size is the paper size, and the strokes are plain <polyline>s with no transforms, fills or text.
  • Strokes are ordered to keep pen-up travel short, and each ring starts at the vertex closest to where the last stroke ended.
  • Rings are kept at least the minimum ring spacing apart, measured on each ellipse's narrow axis. Below the line width they overlap and build up shading; tighter rings would only pile ink on ink, so they are left out and counted as skipped.
  • Plot times use strek's default speeds (150 mm/s drawing, 200 mm/s travel, a 3 mm lift per stroke).
